## iPhone und iPad (Testphase)

Keine App-Store-Version. Die Apps laufen als Web-App direkt aus Safari:

1. Link oben in **Safari** öffnen (nicht Chrome oder Firefox).
2. Unten auf **Teilen** tippen, dann **„Zum Home-Bildschirm“**.
3. App einmal mit Netz über das neue Symbol starten – danach läuft sie offline.

Wichtig: Ohne Home-Bildschirm löscht Safari Bootsdaten, Notizen und Wetterstand nach 7 Tagen ohne Nutzung. GPX-Dateien über „GPX importieren“ im Törn-Tab laden; Teilen aus anderen Apps direkt in die Skipper-App geht unter iOS nicht.
